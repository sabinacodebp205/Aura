# AURA

AURA is a static, responsive prototype for a premium AI fashion customization platform.

## Pages

- `index.html` - home, search, categories, hero, product grids, AI collection blocks
- `product.html` - product details, gallery, reviews, sizes, colors, related products
- `studio.html` - AI design studio with print and embroidery preview controls
- `cart.html` - cart, design fees, embroidery fees, quantity controls, checkout summary
- `favorites.html` - saved products
- `profile.html` - profile, orders, addresses, payment methods, settings
- `inspiration.html` - Pinterest-style clothing design inspiration gallery
- `community.html` - published community designs and social actions

Open `index.html` directly in a browser to view the prototype.
